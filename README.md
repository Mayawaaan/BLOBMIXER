BLOBMIXER

An interactive 3D application that allows users to generate, mix, and morph organic "blob" shapes in real-time. This project leverages the power of WebGL and custom shaders to create a visually satisfying and playful experience directly in the browser.

## 🚀 Features

* **Real-time Mixing**: Interact with 3D blobs that respond to user input.
* **Custom Shaders**: Utilizes GLSL for fluid, organic shape deformations and unique material effects.
* **Performance**: Optimized for smooth 60fps rendering.
* **Responsive**: Adaptive canvas that works across different screen sizes.

## 🛠️ Tech Stack

* **Framework**: [React](https://reactjs.org/)
* **Build Tool**: [Vite](https://vitejs.dev/)
* **3D Library**: [Three.js](https://threejs.org/) / [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
* **Shaders**: GLSL (OpenGL Shading Language)
* **Deployment**: Vercel
